### What I learned

This challenge helped me get comfortable with centering elements using Flexbox on both axes. I also practised using `border-radius` to give the card and image a polished, rounded feel.

One thing I paid attention to was keeping the layout clean with `gap` inside a flex column instead of adding margins to individual elements:

```css
.container {
    display: flex;
    flex-direction: column;
    gap: 1.2rem;
}
```

I also added a footer attribution below the card, linking back to Frontend Mentor and my own GitHub profile.
